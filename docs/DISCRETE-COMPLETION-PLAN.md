# Discrete Completion Plan Archive

This file is intentionally no longer a launch checklist.

The original June 2026 plan was useful while the PQ wallet, account-number, fee,
wire-format, and testnet pieces were still being ported. It is now obsolete and
has been replaced by the focused documents below:

- `docs/PQ-WIRE-FROZEN.md` for transaction format and domain constants.
- `docs/PQ-FEES.md` for fee floors and wallet fee behavior.
- `docs/WALLET-BEHAVIOR.md` for wallet semantics and test coverage.
- `docs/WALLETD-PQ.md` and `docs/WALLETD-HD.md` for walletd operation.
- `docs/TESTNET.md` for local testnet bring-up.

Do not use this archived filename as evidence of remaining product gaps. Current
readiness work should be tracked in issues or in a fresh release checklist.
